# Transparent Notepad

A simple C# Windows Forms application that utilizes the Win32 API `SetWindowDisplayAffinity` to exclude the window from screen recording and screen sharing tools.

## Prerequisites

- .NET 10.0 SDK (or later)
- Windows 10/11

## Build & Run

```bash
dotnet build
dotnet run
```

## User Experience

**Keyboard shortcuts**:
Ctrl+N - New file
Ctrl+O - Open file
Ctrl+S - Save file
Ctrl+Shift+S - Save As

drag-and-drop support for files
